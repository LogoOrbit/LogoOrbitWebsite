# /cart, /checkout, /search and /brief/*.html are deliberately kept out of the
# index, but they are NOT disallowed here, and that is on purpose. A crawler
# that is refused the URL never fetches the page, so it never reads the
# `noindex` on it - the directive and the block cancel each other out, and the
# URL can still surface from a link somewhere else with nothing to suppress it.
# Letting the crawl through is what lets the noindex do its job:
#   /cart, /checkout, /search   <meta name="robots" content="noindex,nofollow">
#   /brief/*.html               X-Robots-Tag: noindex, nofollow  (next.config.js)
#   /clients                    X-Robots-Tag: noindex, nofollow, noarchive
#
# /clients is the staff portal for issued client certificates. It is behind a
# password and the documents it serves are streamed by /api/clients/*, which
# the Disallow above already keeps crawlers out of. The portal page itself is
# left crawlable for the reason given above: so the noindex is actually read.
